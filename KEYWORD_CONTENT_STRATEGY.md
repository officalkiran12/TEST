## CONTENT OPTIMIZATION GUIDE

### On-Page Optimization Checklist

#### Title Tags (55-70 characters)
```
✓ Include primary keyword
✓ Include location (if relevant)
✓ Include year for relevance
✓ Include benefit/action word
✓ Keep under 70 characters

Examples:
- "Government Jobs Nepal 2026 | 3,000+ Live Positions"
- "Remote Developer Jobs Worldwide | Tech Careers 2026"
```

#### Meta Descriptions (150-160 characters)
```
✓ Include primary keyword
✓ Include secondary keyword
✓ Include call-to-action
✓ Be compelling and benefit-focused
✓ Include numbers/statistics
✓ Keep under 160 characters

Examples:
- "Find 2,000+ government jobs in Nepal. Real-time listings updated daily. Apply now to government positions and get hired. Official portal."
- "Search 100,000+ remote tech jobs worldwide. Filter by salary, company, and skills. Find your perfect role today. Remote work opportunities."
```

#### Header Tags
```
H1: Only ONE per page - primary keyword focus
H2: 3-5 secondary keywords
H3: Long-tail keywords and supporting topics
H4: Subtopics and details

Best Practices:
- H1 should match or be similar to title tag
- Keywords should be naturally distributed
- Hierarchy should be logical
- Don't skip header levels
```

#### Image Optimization
```
Format: JPEG for photos, PNG for graphics, WebP for modern browsers
Size: Compress to <100KB for web
Dimensions: Optimize for responsive design
Alt Text: Descriptive, include keywords naturally
Filename: Descriptive, hyphen-separated

Example:
Filename: best-government-jobs-nepal-2026.jpg
Alt Text: "Government job portal showing top positions in Nepal for 2026"
```

#### Internal Linking
```
Strategy:
- Link related job categories
- Link from blog to landing pages
- Link search pages to category pages
- Use descriptive anchor text (not "click here")
- Aim for 3-5 internal links per page

Examples:
- "Check out our [remote jobs in Nepal](link)"
- "Learn more about [government positions](link)"
```

#### URL Structure
```
Best Practice: /category/subcategory/keyword

Examples:
✓ /jobs/government/teaching
✓ /jobs/remote/developer
✓ /jobs/private-sector/banking
✓ /blog/how-to-find-government-jobs

Avoid:
✗ /jobs?id=123
✗ /page/jobs/category_id=5
✗ /job/asdfghjkl
```
